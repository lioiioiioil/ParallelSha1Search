5. CreateProcess

ФАЙЛЫ
main.cpp — ввод хеша, перебор и организация вычислений.
sha1.hpp — вычисление SHA1.
examples.txt — тестовые пары и команды сборки/запуска.
explanation.txt — этот разбор.

КАК РАБОТАЕТ CREATEPROCESS
Здесь ровно 9 вычисляющих процессов: родитель с номером 0 и 8 дочерних с номерами 1–8.
Родитель тоже перебирает пароли. Отдельного десятого координатора нет.
Процессы, в отличие от потоков, обычно не видят память друг друга.
Обычная глобальная переменная found здесь не стала бы общей.

CreateFileMappingA создаёт общую область памяти размером Shared.
INVALID_HANDLE_VALUE означает, что обычный файл на диске не нужен.
SECURITY_ATTRIBUTES с TRUE разрешает наследование дескриптора этой области.
MapViewOfFile отображает область в адресное пространство каждого процесса.
В Shared лежат found и result[8]: семь символов ответа и завершающий ноль.
Новая область заполняется нулями, поэтому изначально флаг равен 0.

Родитель находит путь к своему .exe через GetModuleFileNameA.
CreateProcessA запускает этот же .exe ещё восемь раз с аргументами:
номер работника, целевой хеш, числовое значение дескриптора общей памяти.
Кавычки вокруг пути позволяют запускать программу из папки с пробелами.
TRUE у CreateProcessA разрешает наследование дескриптора.
STARTUPINFOA задаёт параметры запуска; PROCESS_INFORMATION возвращает дескрипторы.
hProcess сохраняем для ожидания, hThread сразу закрываем: отдельно ждать его не нужно.

Новый процесс начинает main заново. argc == 4 отличает дочерний режим:
аргументы читаются, наследованный дескриптор переводится обратно в HANDLE,
общая память отображается, выполняется search(id), затем ресурсы освобождаются.
Это служебные аргументы программы, вручную их вводить не надо.

search проверяет i = id, id + 9, id + 18, ...
InterlockedCompareExchange(&found, 0, 0) безопасно читает общий флаг.
InterlockedCompareExchange(&found, 1, 0) ставит 1, только если там ещё 0.
Только победитель записывает пароль. Само volatile не обеспечивает синхронизацию:
она обеспечивается Interlocked-функциями.

Родитель ищет свою часть, затем WaitForSingleObject ждёт каждого ребёнка.
GetExitCodeProcess проверяет, что ребёнок завершился без ошибки.
Результат читается после ожидания, когда никто уже не пишет result.
CloseHandle и UnmapViewOfFile освобождают ресурсы.
При ошибке создания ставим общий флаг остановки и ждём уже созданных детей.
Версия использует Windows API; на Mac её можно выполнять через Wine.

ВВОД И ПЕРЕБОР
Группа 501, номер 2: X = 503; X % 3 = 2; M = X % 7 + 3 = 9.
Пароль — ровно 7 символов из 0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ.
Пользователь вводит корректный SHA1 в нижнем регистре; проверок ввода нет.
SHA1 не расшифровывается: сравниваем хеш каждого кандидата с введённым.
Всего 62^7 = 3 521 614 606 208 вариантов. Для номера нужен 64-битный целый тип.
Остаток number % 62 выбирает символ, деление number /= 62 переходит к следующему.
Заполняем пароль справа налево, сохраняя ведущие нули: 0 -> 0000000, 62 -> 0000010.
Полный перебор может занять очень много времени. Примеры используют ранние кандидаты.

ЧТО ПРОИСХОДИТ В SHA1
sha1.hpp реализует SHA1 только для 7 символов этого варианта.
rotate выполняет циклический сдвиг. w[80] — рабочие 32-битные слова.
Семь байтов пароля дополняются битом 1, нулями и длиной 56 бит.
Для такого пароля достаточно одного 512-битного блока SHA1.
80 раундов меняют a, b, c, d, e по стандартным формулам и константам.
Пять итоговых чисел дают 160 бит, которые записываются как 40 hex-символов.
Все рабочие переменные локальные; одновременные вычисления друг другу не мешают.

ПРОВЕРКА
Свежая сборка исходников: без ошибок и предупреждений.
30 основных запусков прошли: 26 на исходной программе, 4 на временных копиях.
Проверены цифры/оба регистра букв в пароле, ведущие нули, все номера работников,
повторные старты и остановки. На временных копиях: пустые части диапазона,
последний кандидат, отсутствие совпадения и верхняя граница ZZZZZZZ.
Полный диапазон из 62^7 вариантов не перебирался; исходный лимит не изменён.
SHA1 сверён с Python hashlib на 5005 строках; ошибок ASan/UBSan нет.
Среда: MinGW + Whisky/Wine на Mac. Visual Studio и сама Windows не проверялись.
Все пары пароль/SHA1 из examples.txt проверены независимо.
